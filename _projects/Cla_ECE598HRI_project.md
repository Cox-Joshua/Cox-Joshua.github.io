This was a class I took in grad school to learn more about human-robot interaction. I learned a lot about this area of engineering and had fun with my group in the final project. I designed and made a pen mount for a UR3 robot arm and also helped develop the hand pose recognition code in order to have the robot draw via gestures. We used MediaPipe’s hand landmark detection and the HaGRID dataset. We additionally programmed the arm to pick and place blocks also using gestures.
